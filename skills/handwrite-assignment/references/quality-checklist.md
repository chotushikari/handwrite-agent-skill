# Page quality checklist

Use this checklist after rendering each page.

## Content
- [ ] Every planned section appears.
- [ ] No required subtopic was omitted.
- [ ] Definitions and explanations are academically correct.
- [ ] Equations and symbols are accurate.
- [ ] Diagram arrows, labels, and table values are correct.
- [ ] No unsupported facts or invented citations were added.

## Image
- [ ] One page per image.
- [ ] Portrait notebook-page framing.
- [ ] Full page visible; no clipped edges.
- [ ] Text is readable at normal zoom.
- [ ] No garbled or duplicated lines.
- [ ] Blue ink only unless the user requested otherwise.
- [ ] No unwanted coloured highlights.

## Handwriting
- [ ] Letter size and shape are not perfectly uniform.
- [ ] Spacing and baseline have mild natural variation.
- [ ] Underlines, bullets, and diagrams look hand-drawn.
- [ ] Irregularity does not damage legibility.
- [ ] The result does not look like a polished infographic or a handwriting font.

## Sequence
- [ ] Continuation pages do not repeat the title/header.
- [ ] Paper and ink appearance remain broadly consistent.
- [ ] Page order follows the page plan.

## Completion
- [ ] Every source requirement maps to a rendered page.
- [ ] Any image-model text uncertainty is disclosed.
- [ ] Unrendered pages are not reported as complete.
