# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature if enabled for this repository, or contact the maintainers through the private contact method listed in the repository profile.

## Sensitive data

- Never commit API keys, tokens, credentials, or private image URLs.
- Do not include private student records in public examples or evaluations.
- Provider adapters should read secrets from environment variables or a secret manager.
- Avoid logging user documents, handwriting references, or generated page content by default.
